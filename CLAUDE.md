# thedozone2

Kotlin/JS PWA (Kotlin Multiplatform, JS-only target). No UI framework — custom DOM via
kotlinx.html, built on the `zoned` framework (`io.4rc:zoned-js`, plugin `io.4rc.zoned.plugin`).

## Build & test
- **Run tests with `./test.sh`** (gitignored; generated by the Zoned plugin). Runs `allTests` on
  its OWN 6g Kotlin daemon with `--build-cache`, so it coexists with a running `./watch.sh`.
  Filter with `./test.sh --tests "*FooTest*"`.
- **Do NOT run `./gradlew jsBrowserTest` directly** while `watch.sh` runs — the test bundle OOMs
  on the default 4g Kotlin daemon and competes with watch's compile.
- **NEVER `./gradlew --stop`** — it kills the developer's running `watch.sh` daemon.
- `./watch.sh` runs continuously (possibly several sessions): compiles `jsMain` + serves :3000.
  It watches `jsMain`, not `jsTest`, so test-only edits don't trigger it. Compile errors → `.build_errors`.
- Tests run in Karma headless Chrome.

## Conventions
- Element ids / CSS classes are centralized in `tdz.view.DomIds` and `tdz.view.CssClasses` — no raw
  strings. Invariant: nothing inside a card may carry a `card-`-prefixed id (matches
  `DomIds.CARD_SELECTOR` and hijacks drag) — use `DomIds.diagramCanvas` etc. for child elements.
- Domain is value-typed (`CanvasName`, `ColumnId`, `CardRef`); events are sealed `data class`es on
  an `EventBus` (no string dispatch). Prefer enums/sealed types over magic strings.
- The `zoned` framework is a separate repo at `/expanse/code/startup/zoned`. After editing it,
  `./publish.sh` republishes to mavenLocal; dependents pick it up as `1.0-SNAPSHOT` (triggers a
  watch `--refresh-dependencies`).
